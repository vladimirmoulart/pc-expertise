# PC Expertise

Base du futur site professionnel de PC Expertise, développée avec Next.js, TypeScript, Tailwind CSS et ESLint.

## Développement

```bash
npm install
npm run dev
```

## Vérifications

```bash
npm run lint
npm run build
```

## Structure

- `src/app` : routes, layouts et styles globaux
- `src/components/layout` : futurs composants de structure
- `src/components/ui` : futurs composants d'interface réutilisables
- `src/lib` : configuration et utilitaires partagés
- `src/types` : futurs types métier partagés
- `public` : ressources statiques servies publiquement (logos optimisés dans `public/images`)
- `design/logos` : fichiers sources des logos, non publiés
